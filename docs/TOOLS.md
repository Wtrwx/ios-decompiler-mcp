# MCP tools

Generated by `scripts/document_tools.py`. The MCP `tools/list` response supplies
the selected profile's schemas. Default focused discovery advertises 19 tools; `tool_profile=full`
advertises all 70. `platform_tool` loads advanced schemas/calls on demand. Results use
a consistent `ok`, `data`, `error`, `request_id`, `elapsed_ms` envelope. Inputs reject unknown fields.

Names marked **mutation** may change instrumentation, local projects, or device state.
Installation, uploads, launch, termination, uninstall and manual rollback
additionally require an exact local-operator approval. Observation hooks do not replace methods.

Default main executable, background job; module_name/path selects an app framework. action=modules lists bounded loaded candidates without dumping. Returns verified cryptid=0/UUID/SHA-256 and binary_path for objc_dump or ida_open_binary; no IPA packaging or forced framework loading. |

Stop removes hooks; an active log stream keeps the session alive. |
